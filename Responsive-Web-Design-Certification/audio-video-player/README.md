# Audio Video Player

A simple webpage demonstrating how to embed and control audio and video content using HTML5.

## 📸 Preview
![Project Screenshot](./screenshots/screenshot.png)

## 🎯 Project Goals
* **Objective:** Learn how to embed audio and video elements in a webpage.
* **Key Lessons:** Gained experience using `<audio>` and `<video>` tags with controls and sources.

## 🛠️ Technologies Used
* **HTML5:** Multimedia elements and semantic structure.
* **CSS3:** Basic styling.

## 🚀 How to Run
1. Navigate to this folder: `cd Responsive-Web-Design-Certification/audio-video-player`
2. Open `Audio-Video-Player.html` in your browser.
