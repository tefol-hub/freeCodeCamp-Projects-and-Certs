# Customer Complaint Form

A functional complaint form featuring conditional field visibility.

[Live Demo](https://tefol-hub.github.io/freeCodeCamp-Projects-and-Certs/Responsive-Web-Design-Certification/customer-complaint-form/)

## 📸 Preview
![Project Screenshot](./images/screenshot.png)

## 🎯 Project Goals
* **Objective:** Practice advanced form elements and conditional styling.
* **Key Feature:** Used the CSS `:has()` pseudo-class to show the "Attach Photo" field only when "Product Defects" is selected.

## 🛠️ Technologies Used
* **HTML5:** Forms, Select menus, and File inputs.
* **CSS3:** Linear gradients, Flexbox, and the `:has()` selector.

## 🚀 How to Run
1. Navigate to: `cd Responsive-Web-Design-Certification/customer-complaint-form`
2. Open `index.html` in your browser.
