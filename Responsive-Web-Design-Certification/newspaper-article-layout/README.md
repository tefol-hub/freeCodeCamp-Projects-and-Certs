## 🎯 Project Goals
* **Objective:** Master typography and print-style layout techniques in CSS.
* **Key Feature:** Used `::first-letter` to create a bold drop cap and `text-indent` for traditional paragraph formatting.
* **Design:** Applied high-contrast typography using serif and sans-serif font pairings for an authentic newspaper feel.

## 🛠️ Technologies Used
* **HTML5:** Semantic article structure.
* **CSS3:** Typography controls, pseudo-elements, and box-model spacing.
