## 🎯 Project Goals
* **Objective:** Practice advanced CSS layout and decoration techniques.
* **Key Feature:** Used CSS 2D transforms (`rotate`, `scale`, `translate`) to create realistic "Security Stamps" and the `blur` filter to hide sensitive data.

## 🛠️ Technologies Used
* **HTML5:** Semantic document structure.
* **CSS3:** Transform properties, Box shadows, and Filters.

2. Open `index.html` in your browser.
